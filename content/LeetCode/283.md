
[283. Move Zeroes](https://leetcode.com/problems/move-zeroes/)



### Solution

```python
class Solution(object):
    def moveZeroes(self, nums):
        """
        :type nums: List[int]
        :rtype: None Do not return anything, modify nums in-place instead.
        """            
        
        zero_list= []
        i = 0
        while i != len(nums):
            if nums[i] == 0 :
                nums.pop(i)
                zero_list.append(0)
            else:
                i+=1

        nums.extend(zero_list)
```
