### Problem

Given a string `s`, reverse only all the vowels in the string and return it.

The vowels are `'a'`, `'e'`, `'i'`, `'o'`, and `'u'`, and they can appear in both lower and upper cases, more than once.

**Example 1:**

**Input:** s = "IceCreAm"

**Output:** "AceCreIm"

**Explanation:**

The vowels in `s` are `['I', 'e', 'e', 'A']`. On reversing the vowels, s becomes `"AceCreIm"`.

**Example 2:**

**Input:** s = "leetcode"

**Output:** "leotcede"

**Constraints:**

- `1 <= s.length <= 3 * 105`
- `s` consist of **printable ASCII** characters.


### sketch

1. Collect the vowels -> `vowel_list`
2. Get the position of the vowels and make the list `pos_vowel`
3. revert the `pos_vowel` list,  put the vowels in `vowel_list` in `pos_vowel` order....


### Solution
```python
class Solution(object):

    def reverseVowels(self, s):
        """
        :type s: str
        :rtype: str
        """
        ret = ""
        vowel_list = []
        vowel_pos = []
        str = []
        for i, char in enumerate(s):
            str.append(char)
            if char.lower() in {'a', 'e', 'i', 'o', 'u'}:
                vowel_pos.append(i)
                vowel_list.append(char)

        vowel_pos.reverse()
        
        for i in range(len(vowel_pos)):
            pos = vowel_pos[i]
            v = vowel_list[i]
            str[pos] = v

        ret = ''.join(str)
        return ret
```
